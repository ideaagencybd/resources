About this library

Four separate courses and a reference vault, rebuilt as one flat website that runs from a folder with no server at all.

What is in here

This library combines four complete courses plus their shared reference vault. Nothing has been summarised away: the original lesson order, section structure and wording are preserved, and the tables, prompts, worksheets and exercises are all intact. What has been added is navigation — one index, one search, one progress system, and cross-links between a tool and everywhere it appears.

The Situations Library

The situations are original content authored for this library rather than extracted from the courses. Each one follows a fixed anatomy so that under pressure you always know where to look: what is happening, what is really going on underneath it, the ordered moves, exact words you can borrow, what reliably makes it worse, what to do once the pressure drops, and the line at which it stops being yours to handle alone. Severity is marked low, medium, high or critical; critical means act, do not deliberate.

How it is built

This is a flat static website. Every page is a self-contained HTML file, and all 917 files — pages, stylesheet, script, search index — sit in a single directory with no subfolders and no build step.

  • No server needed. Open index.html directly from the folder and everything works, including search, filters, dark mode and progress.
  • No network calls. Content is baked into each page rather than fetched, which is what makes file:// viable — browsers block cross-origin reads of local files.
  • Fonts degrade gracefully. Web fonts load from a CDN when you are online and fall back to good system serif and sans faces when you are not.
  • Local-only state. Ticks, saves and last position use this browser’s localStorage under the rh: prefix. Nothing is transmitted.

How to read it

  • Front to back: start with the Mastery track and work down each level. Tick lessons off as you go; the track and progress pages fill in.
  • By problem: go to the Situations Library, find the thing that is actually happening, and read only that page.
  • By instrument: use the Toolkit to find a named tool, then jump to the lesson that teaches it properly.
  • By search: press / anywhere to search every lesson, entry, tool and situation at once.

Keyboard

  • / or Ctrl/Cmd + K — open search
  • ↑ ↓ — move through results, ↵ to open
  • Esc — close search

Limits, honestly

This is a study edition for personal use. The Situations Library describes general principles and cannot account for your jurisdiction, your specific facts, or your risk. It is not legal, medical, or financial advice. Where a situation involves danger to life, the correct first action is always to contact your emergency services.
